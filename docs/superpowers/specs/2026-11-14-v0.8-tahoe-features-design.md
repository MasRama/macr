# Macr 0.8: Spotlight views, Assign to Desktop, Focus modes, Control Center, Stickies

Ren picked five features from the list of macOS behaviour Macr still lacks
and asked for them to be built and pushed one after the other ("gas 1-5
smpe push"). They share nothing, so each is its own commit. Calls made
without asking are marked *(call)*.

## 1. Spotlight views (macOS Tahoe)

Tahoe's Spotlight has four views next to its search field: Apps, Files,
Actions and Clipboard, on Cmd+1 to Cmd+4.

- Four round buttons at the right of the search field; Super+1..4 and
  Ctrl+1..4 switch to a view, the same keys or a click on the lit button
  go back to everything. Esc clears the text, then leaves the view, then
  closes.
- **Apps**: only the applications provider, uncapped. Empty field: the most
  used apps (`Shell.AppUsage`), then every app A to Z.
- **Files**: recent files (`recently-used.xbel` through `GLib.BookmarkFile`)
  and GNOME's file providers (Files/Nautilus, localsearch/tracker). Empty
  field: the 20 newest recent files.
- **Actions**: GNOME's system actions (`SystemActions`: Lock Screen, Log
  Out, Suspend, Power Off, Restart, Screenshot…), Macr's own (Dark Mode,
  Do Not Disturb, Empty Trash, Mission Control, Launchpad) *(call)*, and the
  apps' desktop actions ("New Private Window — Firefox"). Empty field: every
  system and Macr action. In the everything view, up to four matching
  actions get a section after the apps.
- **Clipboard**: hands over to the clipboard history panel (it already looks
  like Tahoe's), with the typed text, through a shared link. No button when
  the clipboard history is off.
- Views list results without a Top Hit and without per-section caps.

## 2. Assign to Desktop

macOS: Dock icon → Options → Assign To: All Desktops / This Desktop / None.

- The Dock icon's menu gets **Assign To** with those three, checked as set.
- Setting `dock-app-desktops` (`as`, entries `app-id=all` or `app-id=N`, N the
  desktop's index when assigned).
- A new window of an assigned app goes to its desktop (`change_workspace`)
  or onto every desktop (`stick`). A desktop that no longer exists is added
  at the end first (through Mission Control's fixed Spaces when it runs,
  else `append_new_workspace`) *(call)*. Windows already open are moved when
  the choice is made.
- Logic in `logic/`: parsing, setting and the decision for a window.

## 3. Focus modes

macOS Focus: Do Not Disturb, Work, Personal, Sleep, each with apps allowed
to notify and an optional schedule.

- Modes: Do Not Disturb, Work, Personal, Sleep *(call: the four macOS ships
  with, no custom ones)*. Each has a list of allowed apps and an optional
  daily schedule (start, end) *(call: every day, no day picker)*; Sleep
  defaults to 22:00–07:00, off until turned on.
- Control Center: the Focus tile gets a menu listing the modes; the tile
  turns the last mode on or off. The bar icon is the mode's (moon, briefcase,
  person, bed).
- While a mode is on, banners from apps not allowed are not shown; they
  still go to the Notification Center. Any mode turns GNOME's
  `show-banners` off, and the Focus tile swaps GNOME's per-app policy getter
  so allowed apps get through *(call)*; GNOME's own DND switch keeps
  working both ways.
- A schedule turns its mode on at the start and off at the end (checked
  every minute); turning a mode off by hand during its window keeps it off
  until the next start.
- Settings: a Focus page with each mode's allowed apps and schedule.

## 4. Control Center: Now Playing and your own layout

- A **Now Playing** tile (two columns wide) in the Control Center: cover,
  title, artist, previous / play-pause / next, for the MPRIS player that
  played last; hidden when no player is open. Reuses the Now Playing
  widget's MPRIS code.
- **Your own layout**: in Macr's settings, the Control Center page lists the
  tiles (Wi-Fi, Bluetooth, Focus, Stage Manager, Now Playing, Display, Sound,
  and the rest GNOME has) with a switch each to show or hide them *(call:
  show/hide, no drag to reorder)*.

## 5. Stickies, Reminders and Quick Note

- **Stickies widget**: a yellow note on the desktop (and in the Notification
  Center) you click to type in; text is saved as you type. Colours: yellow,
  blue, green, pink, purple *(call)*.
- **Reminders widget**: a to-do list; type in "New Reminder" and press Enter
  to add, click the circle to tick one off (it fades and goes after a
  moment).
- Both store their content in settings (`widget-notes`, `widget-reminders`
  as JSON strings) *(call: no files)*.
- **Quick Note** hot corner action: a new sticky note by the corner, on the
  pointer's monitor and above the windows (desktop widgets sit under them),
  typed into at once; it is saved with the Stickies notes *(call)*.
- Typing takes a keyboard grab while the note is being edited; a click
  elsewhere or Esc ends it.

## Non-goals

Reordering Control Center tiles by drag, custom Focus modes, syncing notes or
reminders anywhere, Spotlight actions that need apps' App Intents.
